# Address Map Links demo vault

This is an [Obsidian](https://obsidian.md/) vault demonstrating features of the [Address Map Links](https://github.com/mnaoumov/obsidian-address-map-links) plugin.

## Opening this vault

- **If you already have the plugin installed**, run the **`Address Map Links`: Open demo vault** command — it downloads and opens the latest demo vault automatically.
- **Otherwise**, download `address-map-links-demo-vault.zip` from the [plugin releases](https://github.com/mnaoumov/obsidian-address-map-links/releases), unzip it, and in Obsidian choose `Manage vaults...` → `Open folder as vault` → select the `address-map-links-demo-vault-<version>` folder it unzips into.

On first open, Obsidian treats the vault as untrusted — choose **Trust author and enable plugins** (or enable Community plugins manually), then open [00 Start](<./00 Start.md>).
